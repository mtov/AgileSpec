# PodLite v0

[PodLite](../README.md) | [AgileSpec](../../../README.md)

This version captures the project after inception, before any user story
has been implemented.

## Project Specs

- [Backlog](AgileSpec/project/backlog.md)

  Lists the initial user stories in priority order, all planned.

- [Architecture](AgileSpec/project/architecture.md)

  Defines Python, Streamlit, SQLite, standard-library RSS handling,
  and pytest as the technology stack. Separates UI, services, and
  persistence, with database access handled through services.

- [UI](AgileSpec/project/ui.md)

  Defines native Streamlit styling, vertically organized content,
  English labels, and confirmation before destructive actions.

- [Database](AgileSpec/project/database.md)

  Defines local SQLite storage, parameterized queries, and transactions.

- [Definition of Done](AgileSpec/project/definition-of-done.md)

  Defines shared completion criteria, including approved consolidation.
